Learn 02 · Make a skill

スキルは、3つ書けばできる。

名前、説明文、手順。下のスキルメーカーに入力すれば、そのまま使えるファイルができます。

まずは1つ、一緒に作ってみましょう。

013つを書く 02スキルメーカー 03登録する 04うまくいかないとき
01

書くのは、この3つだけ。

1 · NAME

名前

英小文字とハイフンで。

weekly-report
2 · DESCRIPTION

説明文

何をするか＋どう頼まれたら使うか。

週報を作る。「週報」と頼まれたら使う。
3 · STEPS

手順

やることを順番に。やらないことも。

1. 終わったことを書く…
POINT1つのスキルには、1つの仕事だけ。小さく作るほど、うまく動きます。
02
